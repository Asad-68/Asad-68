## 🖋️ TSSA-Net — Handwritten Devanagari Recognition

**TensorFlow | Keras | EfficientNet | CNN | Transformer | Attention**

Research-oriented deep learning project for handwritten Devanagari character recognition.

- 🖼️ 32×32 image preprocessing
- 🔍 EfficientNet-based feature extraction
- 🧩 Lightweight separable convolution operations
- 🎯 Attention-based feature enhancement
- 🤖 Transformer-based contextual modeling
- 🔀 Multi-feature fusion
- 📈 Evaluated using accuracy, precision, recall and F1-score
- 🔥 Grad-CAM visualization for model interpretability

**Result:** Achieved **99.6% accuracy, precision, recall and F1-score** on a 46-class handwritten Devanagari dataset.

## 🏥 Sparse Clinical Imputation for ICU Mortality Prediction

**Python | PyTorch | BiGRU | Autoencoder | PhysioNet 2012**

Research project investigating sequence-aware missing-data imputation for ICU mortality prediction.

- 🧬 Used denoising autoencoder-based imputation
- ⏱️ Modeled temporal clinical sequences using BiGRU
- 📊 Evaluated on **4,000 ICU stays**
- ⚖️ Compared against naive imputation while keeping the classifier architecture fixed
- 📈 Sequence-aware imputation improved mortality prediction by **+0.040 AUPRC** over the best naive method

🔗 [View Repository](https://github.com/Asad-68/SparseClinicalImputation)
