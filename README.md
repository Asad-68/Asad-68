### 🖋️ HFET-Net — Handwritten Devanagari Recognition

**TensorFlow | Keras | EfficientNet | CNN | Transformer | Attention**

A research-oriented deep learning project for handwritten Devanagari character recognition.

The architecture explores **hybrid feature fusion** by combining transfer learning, lightweight convolutional feature extraction, attention mechanisms, and Transformer-based contextual modeling.

* 🖼️ 32×32 image preprocessing
* 🔍 EfficientNet-based feature extraction
* 🧩 Lightweight separable convolution operations
* 🎯 Attention-based feature enhancement
* 🤖 Transformer contextual modeling
* 🔀 Multi-feature fusion
* 📈 Precision, Recall, F1-score and accuracy evaluation
* 🔥 Grad-CAM visualization for model interpretability
